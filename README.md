## 🤝 How to Contribute

Contributions are welcome! If you have a high-quality resource you'd like to add:

1. **Fork** the repository.
2. **Create a new branch** (`git checkout -b feature/new-book`).
3. **Add** your file to the appropriate folder.
4. **Commit** your changes (`git commit -m 'Add new book: [Book Name]'`).
5. **Push** to the branch (`git push origin feature/new-book`).
6. Open a **Pull Request**.
